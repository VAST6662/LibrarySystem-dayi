# 📚 图书管理系统（C++）

![Platform](https://img.shields.io/badge/platform-Windows-lightgrey)
![IDE](https://img.shields.io/badge/IDE-Visual%20Studio%202022-purple)
![Status](https://img.shields.io/badge/status-课程设计-green)

一个用 **Visual Studio 2022 / C++** 写的**图书管理系统**（控制台程序），数据结构课程设计作品。实现了图书信息管理、借书还书、**续借（延长借书）**、逾期管理、热门排行、库存预警等完整功能，数据自动保存到本地文件。


---

## ✨ 功能特性

### 📖 图书信息管理
- 图书信息：编号、书名、作者、出版社、ISBN、价格、馆藏数量
- **添加 / 删除 / 修改 / 查找**（支持编号精确查，书名、作者、出版社、ISBN 模糊查）
- **排序**（按编号、价格、馆藏数量、借出次数）
- **库存预警**：馆藏 ≤ 2 本自动提醒补货

### 🔄 借阅管理
- **借书**：自动记录借书人、借书日期，并计算应还日期（默认借期 30 天）
- **还书**：自动记录还书日期；逾期还书会提示逾期天数和罚款金额
- **续借（延长借书）**：应还日期自动往后推 30 天，最多续借 2 次，**逾期不能续借**
- 借书人**有逾期未还的书时不能继续借书**
- **全部借阅记录 / 按借书人查询**，每条记录都显示当前状态（借阅中 / 已逾期 / 已归还）

### 📊 统计与排行
- **热门图书排行**：按借阅次数排出前 5 名
- **统计信息**：图书种类、馆藏总量、可借数量、已借出、未归还、逾期数量、平均单价

## 🚀 如何运行

1. 用 **Visual Studio 2022** 打开 `LibrarySystem.sln`
2. 选择 **x64** 或 **x86** 平台，点 **本地 Windows 调试器**（或 Ctrl+F5）运行
3. 按菜单数字操作即可

> 💡 数据文件在工程目录下，**从 VS 里运行最省事**；双击 exe 运行的话，要把 `books.txt`、`borrow_records.txt` 放到 exe 旁边。

## 📖 使用说明（菜单）

```
========== 图书管理系统 ==========
1. 添加图书        9. 续借（延长借书）
2. 删除图书        10. 全部借阅记录
3. 修改图书信息    11. 按借书人查询
4. 查找图书        12. 热门图书排行
5. 显示全部图书    13. 库存预警
6. 图书排序        14. 统计信息
7. 借书            15. 帮助说明
8. 还书            0. 保存并退出
```

**借阅规则**：借期 30 天 → 到期前可以续借，每次续借再延长 30 天，最多续借 2 次；逾期未还的书不能续借、不能继续借新书，还书时提示罚款（每天 0.1 元，示意）。
