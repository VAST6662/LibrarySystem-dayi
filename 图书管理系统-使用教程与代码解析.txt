一、运行项目
--------------------------------------------------------------------------------
1. 用 Visual Studio 2022 打开 LibrarySystem.sln（就在本文件夹里）。
2. 顶部把平台选成 x64（或 x86 都行）。
3. 点绿色三角“本地 Windows 调试器”，或直接按 Ctrl+F5 运行。
4. 程序启动后会先自动加载 books.txt（图书）和 borrow_records.txt（借阅记录），
   然后显示主菜单，输入数字按回车就能操作。

第一次运行时如果这两个文件不存在也没关系，程序会提示“从空库开始”，
你添加第一本书后，文件会自动生成。


二、菜单功能逐个讲
--------------------------------------------------------------------------------
主菜单长这样：

    ========== 图书管理系统 ==========
    1. 添加图书        9. 续借（延长借书）
    2. 删除图书        10. 全部借阅记录
    3. 修改图书信息    11. 按借书人查询
    4. 查找图书        12. 热门图书排行
    5. 显示全部图书    13. 库存预警
    6. 图书排序        14. 统计信息
    7. 借书            15. 帮助说明
    8. 还书            0. 保存并退出

下面按编号说明：

【1 添加图书】
    按提示输入：编号、书名、作者、出版社、ISBN、价格、馆藏数量。
    注意：
    - 编号不能重复（重复会提示换一个）；
    - 价格不能是负数；馆藏数量必须大于 0；
    - 新书默认“可借数量 = 馆藏数量”。
    添加完自动保存到 books.txt。

【2 删除图书】
    输入要删的图书编号，程序会先显示这本书的信息，再问你确认（y/n）。
    输入 y 才真的删除，输入其他任何东西都算取消。
    删除后，这本书以前的历史借阅记录还会保留（方便查历史）。

【3 修改图书信息】
    输入图书编号，程序显示原来的信息，然后让你一项一项改：
    - 书名、作者、出版社、ISBN：直接回车表示“不改这一项”；
    - 价格：直接回车保持原价；
    - 馆藏数量：直接回车保持不变。改了馆藏，可借数量会跟着变
      （比如馆藏从 3 变成 5，可借也加 2）。
    编号不能改（编号相当于“身份证号”，靠它区分书）。

【4 查找图书】
    里面有 5 种查法：
    1 按编号查（精确匹配）
    2 按书名查（模糊：输入“三体”能找到《三体》和《三体2：黑暗森林》）
    3 按作者查（模糊）
    4 按出版社查（模糊）
    5 按 ISBN 查（模糊）
    输入关键词回车，符合条件的书会全部列出来。

【5 显示全部图书】
    把所有书列成一张表，最后一列“借出”表示这本书一共被借过多少次。

【6 图书排序】
    4 种排法：
    1 按编号升序
    2 按价格从低到高
    3 按馆藏数量从多到少
    4 按借出次数从多到少（借得多的排前面）
    排完会直接显示，并且把排序结果也保存到文件里（下次打开顺序不变）。

【7 借书】
    输入图书编号 + 借书人姓名。
    程序会做三件事：
    - 检查书是否存在、是否还有可借的数量（可借 0 本会拒绝）；
    - 检查这个借书人有没有“逾期未还”的书，有的话拒绝借书
      （规则：先把逾期的书还了才能再借）；
    - 借书成功：可借数量减 1，并生成一条借阅记录：
      借书日期 = 今天，应还日期 = 今天 + 30 天，续借次数 = 0。

【8 还书】
    输入图书编号 + 借书人姓名。
    - 找到“未归还”的那条记录，把还书日期写成今天；
    - 书的可借数量加 1；
    - 如果已经逾期，会提示：逾期多少天、罚款多少
      （每天 0.1 元，只是示意金额，不真的收钱）。
    注意：借书人和编号必须对得上，否则会提示找不到记录。

【9 续借（延长借书）】
    这是“延长借书”功能，针对还没有还的书：
    - 输入图书编号 + 借书人姓名；
    - 找到“未归还”的那条记录后，检查两个规则：
      规则1：已经逾期的书不能续借；
      规则2：续借次数已经到上限（默认 2 次）不能再续借；
    - 都通过：应还日期往后推 30 天，续借次数 +1。
    示例：张三借了《C++ Primer Plus》，应还 08-19，续借 1 次后变成 09-18。

【10 全部借阅记录】
    把每一条借阅记录列出来，包含：编号、书名、借书人、借书日期、
    应还日期、还书日期、续借次数、状态。
    状态有三种：
    借阅中（没还且没到期）/ 已逾期（没还且过了应还日期）/ 已归还。

【11 按借书人查询】
    输入一个姓名，把这个人所有的借阅记录（含已还的）都列出来。
    适合查“小明一共借过几本书”。

【12 热门图书排行】
    按“被借次数”从多到少排出前 5 名。
    统计用的是借阅记录，所以就算某本书被删了，它的历史借阅次数也能排进来。

【13 库存预警】
    找出馆藏数量 <= 2 本的书，提醒该补货了。
    没有需要预警的书会提示“库存充足”。

【14 统计信息】
    汇总：图书种类、馆藏总量、可借数量、已借出、借阅记录总数、
    未归还记录数、逾期未还数、平均单价。

【15 帮助说明】
    在程序里再看一遍借阅规则和数据文件说明。

【0 保存并退出】
    退出前会把图书和借阅记录再保存一次（其实每次操作都已经保存过了，
    这里再存一次是为了保险），然后退出程序。


三、数据文件说明
--------------------------------------------------------------------------------
程序目录下有两个数据文件，都是纯文本，可以用记事本打开看：

books.txt（图书，每行一本书，用 | 分隔 8 个字段）：
    B001|C++ Primer Plus|Stephen Prata|人民邮电出版社|978-7-115-17660-6|128.00|5|4
     编号 |    书名     |    作者     |   出版社   |      ISBN     | 价格 |馆藏|可借

borrow_records.txt（借阅记录，每行一条，7 个字段）：
    B001|C++ Primer Plus|张三|2026-07-20|2026-09-18|未归还|1
     编号 |    书名      |借书人|借书日期 |应还日期  |还书日期|续借次数

小提示：
- “未归还”三个字是特殊标记，表示这本书还没还；还书后这里会变成日期。
- 想清空数据重来？删掉这两个文件再运行程序就行。
- 想改借阅规则？打开 bookmanager.h，改这几个常量：
      BORROW_DAYS  = 30（借期天数）
      MAX_RENEW    = 2 （最多续借次数）
      LOW_STOCK    = 2 （库存预警阈值）
      FINE_PER_DAY = 0.10（逾期每天罚款）

四、先看整体：文件分工
--------------------------------------------------------------------------------
项目一共 6 个代码文件，分工很明确：

    main.cpp            程序入口：设置中文不乱码，然后调 bookManageMenu()
    util.h / util.cpp   公共小工具：读数字、读一行、去空格、字符串转数字
    bookmanager.h       头文件：定义数据结构（Book、BorrowRecord）和函数声明
    bookmanager.cpp     核心：图书管理全部功能的实现（代码最多）
    books.txt           数据文件（不是代码）
    borrow_records.txt  数据文件（不是代码）

为什么要拆文件？
  把“工具”和“业务”分开，代码好找、好改。
  util 是“什么都能用的工具箱”，bookmanager 是“图书管理专用”。


五、核心数据结构（bookmanager.h）
--------------------------------------------------------------------------------
程序里有两样最重要的“东西”：书 和 借阅记录。
C++ 里用一个叫“结构体 struct”的东西来定义它们：

    struct Book {
        string id;         // 图书编号
        string name;       // 书名
        string author;     // 作者
        string publisher;  // 出版社
        string isbn;       // ISBN
        double price;      // 单价
        int total;         // 馆藏总量
        int available;     // 可借数量
    };

    struct BorrowRecord {
        string bookId;     // 图书编号
        string bookName;   // 书名（复制一份，方便查看）
        string borrower;   // 借书人
        string borrowDate; // 借书日期
        string dueDate;    // 应还日期
        string returnDate; // 还书日期，"未归还"表示没还
        int renewCount;    // 续借次数
    };

怎么看懂？
  - struct 就是“打包”：把一本书的多个信息打包成一个整体，叫 Book。
  - string 是字符串类型（文字），int 是整数，double 是小数。
  - 程序里用 vector<Book> books; 表示“很多本书”，
    vector<BorrowRecord> records; 表示“很多条借阅记录”。
  - vector 就是“会自动变长的数组”，可以 push_back 往尾部加，
    可以用 [下标] 访问，可以用 erase 删掉某个。

另外在 bookmanager.h 里还定义了 4 个“规则常量”：
    const int BORROW_DAYS = 30;      // 借期 30 天
    const int MAX_RENEW = 2;         // 最多续借 2 次
    const int LOW_STOCK = 2;         // 馆藏 <= 2 预警
    const double FINE_PER_DAY = 0.10; // 逾期每天罚款 0.1 元
为什么要单独提出来？因为规则集中放一起，想改规则只改这里，
不用去满文件找数字，这就是“常量”的好处。


六、程序怎么跑起来的（main.cpp）
--------------------------------------------------------------------------------
main.cpp 就干两件事：

    1) 设置控制台为 UTF-8，防止中文乱码：
         SetConsoleOutputCP(65001);   // 输出用 UTF-8
         SetConsoleCP(65001);         // 输入也用 UTF-8
       这两行是 Windows 特有的函数，所以 main.cpp 里 include 了 <windows.h>。
       为什么需要？因为源码存的是 UTF-8，控制台默认代码页是 GBK，
       不切换的话中文就会显示成乱码。

    2) 调 bookManageMenu() 进入主菜单循环。
       bookManageMenu() 内部是 do...while 循环：先显示菜单 -> 读选择 ->
       执行对应功能 -> 再回到菜单，直到用户选 0 才退出。


七、最常用的几个小工具（util.cpp）
--------------------------------------------------------------------------------
所有菜单都要读输入，所以把“输入处理”抽到 util.cpp，避免重复代码。

  readInt("提示语")     读一个整数。用户输的不是数字就一直重新问。
  readDouble("提示语")  读一个小数，逻辑同上。
  readLine("提示语")    读一行文字（比如书名、姓名），并去掉首尾空格。
  trim(字符串)          去掉字符串首尾的空格/回车。
  strToInt / strToDouble 把字符串完整转成数字，转不了就返回 false。

重点看 readInt 的“防呆”写法：

    int readInt(const string& tip) {
        int n;
        while (true) {
            cout << tip;
            if (cin >> n) {            // 成功读到数字
                cin.ignore(1024, '\n'); // 吃掉回车，免得影响后面的 getline
                return n;
            }
            if (cin.eof()) {           // 输入流结束（Ctrl+Z）
                cout << "\n输入已结束，程序退出。" << endl;
                exit(0);
            }
            cin.clear();               // 清除错误状态
            cin.ignore(1024, '\n');   // 丢掉输错的那一行
            cout << "输入无效，请输入一个整数：" << endl;
        }
    }

讲解：
  - cin >> n 读数字；如果用户输的是字母，读失败，cin 会进入“错误状态”。
  - cin.clear() 把错误状态清掉，cin.ignore() 把错误的那一行丢掉，
    这样程序不会卡死，而是提示重新输入。
  - cin.ignore(1024, '\n') 的意思是“最多丢掉 1024 个字符，直到遇到换行”。
  - eof() 判断：如果输入结束（比如按了 Ctrl+Z），直接退出程序，避免死循环。
  - 这就是为什么你随便乱输入，程序也不会崩溃。


八、文件读写是怎么做的（bookmanager.cpp）
--------------------------------------------------------------------------------
程序用“文件流”读写文件：

    ifstream  in(filename);   // 读文件（input file stream）
    ofstream  out(filename);  // 写文件（output file stream）

读 books.txt（loadBooks 函数）核心逻辑：
    1. ifstream in("books.txt")，打不开就返回空表；
    2. 用 getline(in, line) 一行一行读；
    3. 每行用 splitLine(line, '|') 按 | 拆成 8 段；
    4. 分别塞进 Book 结构体的各个字段；
    5. 检查可借数量：不能为负、不能超过馆藏。

写 books.txt（saveBooks 函数）核心逻辑：
    1. ofstream out("books.txt")；
    2. 遍历 books，一行一个，字段之间用 | 拼起来写出去。
    3. 价格用 fixed << setprecision(2) 固定显示两位小数（128.00）。

为什么要用 | 分隔？
  因为书名、作者里可能有空格，不能用空格当分隔符；| 一般不会出现在
  书名里，比较安全。（如果你见过用逗号分隔的 CSV 文件，思路是一样的。）

注意：splitLine 是“把一行按分隔符拆成数组”：
    vector<string> parts;
    string cur;
    for (char c : line) {
        if (c == sep) { parts.push_back(cur); cur.clear(); }
        else cur += c;
    }
    parts.push_back(cur);  // 别忘了最后一段
这就是“遍历字符串里的每个字符，遇到分隔符就切一刀”的思路。


九、日期是怎么算的（重点：续借功能的原理）
--------------------------------------------------------------------------------
借书、还书、续借、逾期判断都离不开日期。程序里日期统一是
“YYYY-MM-DD”这样的字符串（比如 2026-08-19）。

三个日期函数：

1) getToday() —— 拿今天的日期
    用系统时间：
        time_t now = time(nullptr);
        tm t;
        localtime_s(&t, &now);
        strftime(buf, sizeof(buf), "%Y-%m-%d", &t);
    简单理解：time() 拿到“从 1970 年到现在过了多少秒”，
    localtime_s 把秒换算成年月日，strftime 按格式转成字符串。

2) addDays(日期, 天数) —— 日期加 N 天（续借就靠它）
    核心是把日期转成“秒”，加上天数，再转回日期：
        long long total = dateToDays(date) + days;   // 先转成“第几天”
        time_t sec = total * 86400;                   // 天 转 秒（一天86400秒）
        tm* t = localtime(&sec);
        strftime(buf, sizeof(buf), "%Y-%m-%d", t);
    dateToDays 用 mktime 把年月日转成从 1970 年起的秒数，再除以 86400 得到天数。
    之所以用“中午 12 点”来转，是为了避开夏令时可能造成的 1 天误差（小细节）。

3) daysBetween(晚的日期, 早的日期) —— 两个日期差几天
    就一句：dateToDays(later) - dateToDays(earlier)。
    还书时算“逾期几天”就靠它。

4) 判断是否逾期（isOverdue）：
        return r.returnDate == "未归还" && today > r.dueDate;
    意思是：没还 且 今天比应还日期晚，就是逾期。
    为什么能用 > 直接比较日期字符串？因为 "YYYY-MM-DD" 这种格式，
    字符串比较大小就是日期比较大小（先比年，再比月，再比日），这是设计好的。

借书时（borrowBook 函数）：
    r.borrowDate = today;                          // 借书日期 = 今天
    r.dueDate = addDays(today, BORROW_DAYS);       // 应还 = 今天 + 30 天
    r.renewCount = 0;

续借时（renewBook 函数）：
    先检查两个规则：
        if (isOverdue(r, today)) { ... 逾期不能续借 ... }
        if (r.renewCount >= MAX_RENEW) { ... 超过 2 次不能续借 ... }
    通过后：
        r.dueDate = addDays(r.dueDate, BORROW_DAYS);  // 应还日期再推 30 天
        r.renewCount++;


十、各个功能函数的套路
--------------------------------------------------------------------------------
学会看一个，其他的都差不多。以“添加图书”为例：

    void addBook(vector<Book>& books) {   // 注意 & ：直接改外面的 books
        ...
        while (true) {
            b.id = readLine("请输入图书编号：");
            if (b.id.empty()) { cout << "编号不能为空！"; continue; }
            if (findBookById(books, b.id) >= 0) {
                cout << "该编号已存在，请换一个编号！"; continue;
            }
            break;   // 编号合法且不重复，退出循环
        }
        ... 读其他字段 ...
        books.push_back(b);          // 加进数组
        saveBooks(BOOK_FILE, books); // 保存到文件
    }

关键点：
  - “查重”用 findBookById：遍历数组找相同编号，找到返回下标，找不到返回 -1。
  - 所有“修改数据”的函数都带 &（引用），这样在函数里改 books，
    外面的 books 才会真的变。如果不带 &，函数里改的是“拷贝”，外面不变。
  - 每次操作完立刻 saveBooks/saveBorrowRecords 保存，数据不丢。

“查找图书”用模糊匹配：
    if (b.name.find(key) != string::npos) { ...找到了... }
  string::find 是“找子串”，找不到返回 string::npos（一个很大的数），
  所以“不等于 npos”就说明包含关键词。

“排序”用 sort + lambda：
    sort(books.begin(), books.end(), [](const Book& a, const Book& b) {
        return a.price < b.price;   // 价格低的排前面
    });
  sort 是标准库排序，第三个参数是“比较规则”，返回 true 表示 a 应该排在 b 前面。
  这种写在小括号里的函数叫 lambda 表达式（匿名函数）。
  按借出次数排序时，lambda 里还要用到 records，所以写成 [&records] 捕获引用：
    sort(books.begin(), books.end(), [&records](const Book& a, const Book& b) {
        return countBorrowTimes(records, a.id) > countBorrowTimes(records, b.id);
    });

“热门排行”也是排序：
  先把借阅记录按“书”汇总出每本被借几次，再按次数降序排，
  取前 5 名显示。注意：汇总用的是记录里的 bookName，所以书被删了也能排。


十一、C++ 知识点清单（面试/答辩可能被问）
--------------------------------------------------------------------------------
1. 结构体 struct：把多个不同类型的数据打包成一个整体。
2. vector：动态数组，会自动扩容；常用 push_back / size / [下标] / erase。
3. 引用 &：函数参数用 & 可以直接修改调用者的变量，避免拷贝。
4. const：const 修饰参数表示“只读不修改”；修饰成员函数表示“不改变对象”。
5. string 常用方法：find（找子串）、substr（截取）、empty（是否为空）、
   c_str()（转成 C 风格字符串）。
6. 文件流：ifstream 读、ofstream 写；getline 按行读。
7. sort 排序 + lambda 比较规则。
8. 日期处理：time / mktime / strftime / localtime_s。
9. 输入防呆：cin.clear() + cin.ignore() 处理错误输入。
10. 模块化：头文件放声明、cpp 放实现；#ifndef 防止头文件被重复包含。


十二、常见问题排查
--------------------------------------------------------------------------------
Q1：运行出来中文乱码？
    A：程序已自动切换 UTF-8，一般不会乱。如果还乱，把控制台字体改成
       “新宋体”或“Consolas”，或者在 VS 里：工具 -> 选项 -> 环境 -> 终端，
       把“默认代码页”改成 65001。

Q2：提示读不到 books.txt？
    A：数据文件要和 exe 在同一目录。从 VS 按 F5 运行，工作目录就是工程目录，
       文件都在；如果是双击 exe，就把 books.txt、borrow_records.txt 复制到
       exe 旁边。

Q3：借书提示“有逾期未还”？
    A：这是规则：谁有逾期的书没还，就不能再借新书。先把这个人的逾期书还了。

Q4：续借提示“已达上限”？
    A：每本书每次借阅最多续借 2 次。想放宽，改 bookmanager.h 里 MAX_RENEW。

Q5：数据被我玩乱了，想恢复？
    A：删掉 books.txt 和 borrow_records.txt，重新运行，从空库开始。
       或者把示例文件再复制回来。

Q6：想加新功能（比如读者管理、按日期统计）？
    A：思路：在 bookmanager.h 加结构体/函数声明，在 bookmanager.cpp 写实现，
       然后在 bookManageMenu 的菜单里加一行 case。照葫芦画瓢就行。


十三、怎么上传到 GitHub
--------------------------------------------------------------------------------
1. 在 GitHub 网页上点 New repository 新建一个仓库（名字随意，比如
   library-management-system），不要勾选 “Add a README file”。
2. 打开命令行（在 LibrarySystem 这个文件夹里）：
       git init
       git add .
       git commit -m "第一次提交：图书管理系统"
       git remote add origin https://github.com/你的用户名/仓库名.git
       git branch -M main
       git push -u origin main
   把“你的用户名/仓库名”换成你自己的。
3. 如果第一次提交提示要配置用户名邮箱，先执行：
       git config --global user.name "你的名字"
       git config --global user.email "你的邮箱"
   再重新 commit 一次。
4. 也可以用 GitHub Desktop 图形界面：File -> Add local repository
   选中 LibrarySystem 文件夹 -> Publish repository，更简单。

上传完，别人克隆下来，用 VS 打开 .sln 就能编译运行。
x64、Debug 这些编译产生的文件夹已经被 .gitignore 忽略，不会传上去。
